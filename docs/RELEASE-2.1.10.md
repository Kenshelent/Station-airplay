# Релиз 2.1.10: тёмные обложки и кнопка обновления

## Что вошло

1. **Тёмная обложка с видимым рисунком больше не гасит LED.** Раньше цвет
   брался по самому населённому кластеру; у обложки «чёрный фон + белые штрихи»
   это фон, и индикация выключалась целиком. Теперь при почти чёрном
   доминирующем кластере берётся самый населённый видимый (не менее 0.5 %
   выборки). Полностью чёрная обложка по-прежнему выключает подсветку.
2. **Чёрная точка по умолчанию — серый `#808080`** вместо `#8C4CD9`, и в
   приёмнике, и в панели. Сохранённые пользователем значения не меняются.
3. **Mini 1 получает floor 0.07**: чёрная обложка даёт слабое серое свечение.
4. **Кнопка «Обновить AirPlay» в панели.** Helper по вызову `{update:true,
   attempt}` пишет `/tmp/airplay-update.sh` и запускает его через `setsid`:
   останавливает приёмник (`POST /api/plugins/airplay.airplay-luna/stop`),
   ждёт выхода процесса, ставит `airplay/airplay-luna` из реестра (повтор при
   занятом локе), затем просит Luna включить приёмник. Панель опрашивает
   `/api/plugins` и показывает версию.
5. Пакет и helper теперь `0.1.1`; панель `0.1.1`.

## Сборка

Скрипт сборки — `build-210.sh` в рабочей папке релиза: собирает оба бинарника
(ARMv7, UPX), пересобирает приёмники из `base-2.1.4` через
`package_yampkg.py`, пакует helper-пакеты `0.1.1` через `yam-publish pack` и
затем собирает единый пакет `build-release-bundle.py --luna-min 0.2.28`.
