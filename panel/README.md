# AirPlay Panel

Веб-панель AirPlay живёт внутри единого пакета `airplay/airplay-luna` 2.1.8
как плагин `airplay.panel` (Lua, сервис, только веб-разрешение).

Отдельного пакета панели нет: установка, обновление и удаление выполняются
одной транзакцией YAM. Подробности — в [YAM-REGISTRY.md](YAM-REGISTRY.md).

Страница: `http://<станция>:8099/web/airplay.panel`.

Панель показывает состояние приёмника, цветовые точки обложки, пресеты и
настройки. Она не ходит в сеть, не запускает приёмник и не открывает новых
портов. Helper `airplay.panel-command` включается страницей на один запрос и
не стартует сам.

Файлы панели в репозитории: `main.lua`, `index.html`, `transport.js`,
`web.toml`, `LUNA-LICENSE`. `TESTING.md`-прогоны в `check-panel-e2e.py`
относятся к разработке и не устанавливаются на колонку.
