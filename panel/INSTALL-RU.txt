AirPlay Panel — тестовый комплект БЕЗ обновления Luna

Версия приёмника: 2.1.8-panel.2
Версия интерфейса: 0.1.0-test.2
Версия helper: 0.1.0-test.1
Требуется официальная Luna 0.2.26+ с включёнными web.ui/web.api и
allow_plugin_binaries. Никакой патч Luna или PR #38 не требуется.

В комплекте файлы для 12 платформ. Выбирайте ТОЛЬКО свою модель:

1. station-airplay-2.1.8-panel.2-<model>.yampkg — новый приёмник.
2. airplay-panel-command-0.1.0-test.1-<model>.yampkg — helper команд.
3. airplay-panel-0.1.0-test.2.yap — Lua-вкладка (общая для всех).

До установки сохранить настройки и штатно остановить все YAM binary-плагины
через Luna. Перед каждой транзакцией проверять, что они остановлены:
postinstall приёмника может снова запустить сервисы.
НЕ удалять /tmp/yam/yam.lock.

Установить два .yampkg обычным YAM, например:

yam --platform <model> --profiles /data/yam/platforms install -y /data/local/tmp/station-airplay-2.1.8-panel.2-<model>.yampkg
yam --platform <model> --profiles /data/yam/platforms install -y /data/local/tmp/airplay-panel-command-0.1.0-test.1-<model>.yampkg

После этого загрузить .yap через установку плагинов В ВЕБ-ИНТЕРФЕЙСЕ LUNA.
Не пытаться ставить этот .yap клиентом YAM v2.

Включить:
- AirPlay — как обычно;
- AirPlay Panel Command — включить плагин, НЕ включать автозапуск сервиса;
- AirPlay Panel — включить плагин И автозапуск сервиса.

Появится вкладка AirPlay Panel, прямой путь:
http://<ip>:8099/web/airplay-panel
Это не /calibration.

Есть настройки цветов AirPlay, режим задержки, экспериментальный EQ,
preview, пресеты и импорт/экспорт JSON.
В «Цветах основных точек» отдельно настраиваются серый, красный, зелёный,
синий, жёлтый, голубой, пурпурный, оранжевый и белый; между ними палитра
обложки интерполируется. Чёрная точка — цвет и яркость свечения чёрной
обложки. Правка оранжевого больше не сдвигает красный и жёлтый.
Общей калибровки LED Luna здесь НЕТ. На Алису и штатную музыку EQ не влияет.

Настройки применяются после ручного перезапуска AirPlay — сохранять и
перезапускать с остановленным воспроизведением. Само сохранение не
перезапускает приёмник.

Проверено: Go race/vet, тесты транспорта, точная установка в QEMU Mini
с официальной Luna 0.2.26, ответы после повторов/отмены helper, два клиента,
пресеты и истечение preview, неизменный PID приёмника. Интерфейс проверен
в Chromium на имитаторе backend.
Скорость продления preview на физической колонке, длительное воспроизведение,
реальные цвета и cold boot этого комплекта ещё не подтверждены.

Если helper не успевает продлевать preview, тот безопасно истечёт через 4 с.
Если возник timeout при сохранении, результат неизвестен: сначала заново
прочитайте настройки, не нажимайте повторно вслепую.
При перезапуске приёмника во время работы панели обновите страницу.

ВАЖНО ДЛЯ ОРИГИНАЛЬНОЙ MINI:
Эта ветка сделана от 2.1.7 и НЕ включает отдельные изменения громкости/цветов
кандидата 2.1.8-mini.1. Это независимый комплект для проверки панели,
не замена тому Mini-кандидату. Объединять их нужно отдельно после проверки.

Откат: остановить/отключить Lua-вкладку и helper; штатно остановить AirPlay;
установить прежний приёмник из его файла. Пользовательские настройки
предварительно сохранить. Никакие старые пакеты автоматически не удаляются.

SHA256 файлов — в SHA256SUMS.
Публичный релиз, реестр и четыре физические колонки не изменены.
